# Liquid-TUI reference

Source: https://github.com/Pugbread/Liquid-TUI
Retrieved 2026-10-24. MIT license in LICENSE.

The Status Board desktop-lens experiment adapts the ScreenCaptureKit ->
CVMetalTextureCache -> Metal rendering architecture from DesktopCapture.swift
and the RGB dispersion / neutral tint approach from Render/Shaders.metal.
The small rounded-rectangle lens shader and lifecycle integration are tailored
for Status Board. No terminal, shell, web view or upstream app is included.
